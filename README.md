# Python Learning

This repository contains my Python learning projects, exercises, and experiments, ranging from Python fundamentals to libraries and APIs.

For now, it contains the following directories:
- **python-full-course-bro:** Code I wrote while following [Bro Code's](https://www.youtube.com/@BroCodez) [Python Full Course](https://www.youtube.com/watch?v=ix9cRaBkVe0).

  The main project in this course was a weather app that uses the OpenWeatherMap API to retrieve and display the current weather for a city entered by the user.
